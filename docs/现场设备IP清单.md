## 二、设备清单

| 设备 | 品牌/型号 | IP 地址 | 端口 | 关键参数 |
| --- | --- | --- | --- | --- |
| 上位机（本程序所在主机） | - | `19.87.6.230` | `502`（监听） | 部署 CommandCenter 上位机程序；**做 Modbus 从站监听 502，等 PLC 主站连入并读写上位机寄存器区（D100~D112，V1.12.11 起）** |
| PLC | 汇川 PLC（**主站**） | `19.87.6.1` | - | 做 Modbus 主站，TCP 连入上位机 `19.87.6.230:502` 读写上位机保持寄存器区；寄存器地址与方向见 `docs/通讯接入.md` |
| 相机 1 | 基恩士 IV4（**上相机**） | `19.87.6.213` | 8500（指令口） | T1/T2/RT/PW/OF 指令；**FTP 推图到 `D:\IV存图\1`**（0000.jpeg+0000.iv4p 双文件，V1.12.18 起唯一取图方式；V1.12.22 定稿目录） |

## 三、扫码枪触发指令细节（重要）

| 项 | 值 |
| --- | --- |
| 通讯方式 | 以太网 TCP/IP 无协议（上位机作 TCP 客户端，扫码枪作服务器） |
| 地址 | `19.87.6.100:9004` |
| 触发指令文本 | `LON`（Laser ON，打开激光开始读码） |
| 帧结束符 | 程序发送时自动补 `\r\n`（CRLF，回车+换行） |
| **十六进制命令（程序实际发送，现场验证 OK）** | **`4C 4F 4E 0D 0A`** = `L`(4C) `O`(4F) `N`(4E) + CR(0D) + LF(0A) |

**以代码为准（已实测确认）**：程序 `ScannerTcpService.SendTrigger()` 发送的是
`TriggerCommand.Trim() + "\r\n"`，即 **`LON\r\n`（CRLF，十六进制 `4C 4F 4E 0D 0A`）**，
现场联调已验证 OK（扫码枪进入读码状态、正常推码）。
> 备注：现场最初记录的十六进制为 `4C 4F 4E 0D`（仅 CR），与代码发送的 CRLF 略有出入；
> 因代码实测通过，本文档一律以代码行为（`LON\r\n`）为准，后续现场核对以此值为标准。

## 四、与程序配置（`appconfig.json`）对应关系

现场核对时直接对号入座：

```jsonc
{
  "plc": { "ipAddress": "19.87.6.1", "port": 502 },        // 汇川 PLC（主站）
  "cameras": [                                             // 基恩士相机，两台（V1.12.22 定稿）
    { "name": "上相机", "ipAddress": "19.87.6.213", "commandPort": 8500, "ftpUploadDir": "D:\\IV存图\\1", "programNo": 0 },   // 相机1=上相机（FTP 取图目录 D:\IV存图\1）
    { "name": "下相机", "ipAddress": "19.87.6.212", "commandPort": 8500, "ftpUploadDir": "D:\\IV存图\\2", "programNo": -1 }   // 相机2=下相机（FTP 取图目录 D:\IV存图\2）
  ],
  "scanners": [                                            // 基恩士扫码枪
    {
      "enabled": true,            // 默认启用（V1.12.9 起设置窗体默认勾选）
      "mode": "Tcp",
      "ipAddress": "19.87.6.100",
      "port": 9004,
      "triggerCommand": "LON"     // 发送时程序自动补帧结束符
    }
  ]
}
```

- 上位机自身 IP `19.87.6.230` 不用写进程序配置（是运行主机的网卡地址，配在系统网络里）。
- 配置修改入口：程序"系统设置"窗体（管理员登录）或直接编辑 `Config/appconfig.json`。
- 详细对接流程见 `docs/通讯接入.md`（PLC/相机/扫码枪寄存器与指令表）。

## 五、现场核对注意事项

1. **扫码枪只接受一个 TCP 客户端**（V1.12.5 现场实测）：用网络调试助手等工具占着连接时，上位机连上即被踢，表现为"一直断连"。调试助手测完必须关闭连接再测本程序。
2. 相机走 FTP 推图（基恩士工程师在相机软件里把 FTP 上传目录配置为 `D:\IV存图\1`（相机1/上）与
   `D:\IV存图\2`（相机2/下），上位机按 `CameraConfig.FtpUploadDir` **监听这两个本地目录取图**，
   **V1.12.18 起仅保留 FTP 取图**（每次拍照生成 `0000.jpeg`+`0000.iv4p` 双文件，程序配对归档后删除
   FTP 源文件，FTP 目录只当中转暂存区）；Tcp/BR 直读已下线。
   一台相机拍多个点位时，在设置窗体相机表给各点位配程序号（触发前自动 `PW,nnn` 切换）。
3. 所有设备须与上位机同网段（`19.87.6.x / 24`），能互 ping 通。
