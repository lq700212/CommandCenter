# CommandCenter 使用说明（操作手册）

> 适用人群：现场操作员 / 班组长 / 设备维护工程师。
> 本文只讲"怎么用"，不谈内部实现；通讯/寄存器/指令等对接细节见 `docs/通讯接入.md`，
> 设备 IP 清单见 `docs/现场设备IP清单.md`，通讯架构技术总结见 `docs/上位机通讯封装范式.md`。

---

## 一、软件启动

1. 双击 `CommandCenter.exe`（或桌面快捷方式）启动。
2. 启动即自动铺满屏幕工作区（保留任务栏，不是全屏独占；边框固定不可拖拽缩放，
   最小化 / 关闭按钮正常可用）。
3. 无需登录即可观看主界面；只有点 **"系统设置"** 按钮时才需要登录（见 §五）。

启动失败排查：先看 `Logs/` 目录当日日志，进程起不来的常见原因是 `Config/appconfig.json`
被手改坏（JSON 语法错误 / 字段类型错），删除或修正该文件后重启。

## 二、主界面速览

```
┌──────────────────────────────────────────────────────────────────┐
│ 产品A: [配方▾]  序列号: [框·点击即录]  总数:0  OK:0  NG:0   [系统设置]  ●PLC●扫码枪●相机1●相机2│
├──────────────────────────────────────────────────────────────────┤
│  ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐                    │
│  │  W1  │ │  W2  │ │  W3  │ │  W4  │ │  W5  │   ← 窗口矩阵       │
│  └──────┘ └──────┘ └──────┘ └──────┘ └──────┘      （行列数按配置）│
├──────────────────────────────────────────────────────────────────┤
│ 状态: 等待PLC主站到位信号…                                        │
└──────────────────────────────────────────────────────────────────┘
```

- **标题栏**：产品型号 → 配方下拉框 → 序列号 → 总数 / OK / NG 计数 → 系统设置按钮 → 连接指示灯。
  - 计数默认是"实心彩色块 + 白字"（绿底=OK、红底=NG），醒目且符合现场习惯。
  - 连接指示灯从右到左：相机… → 扫码枪 → PLC。绿=已连接、红=断连/故障。
    PLC 灯三态：**绿**=主站已连入、**黄**=监听就绪等主站、**红**=监听失败（鼠标悬停有排查提示）。
  - 各字段可按配置开关显隐（标题栏更紧凑），现场不需要的字段可让管理员在设置里关掉。
- **窗口矩阵**：每格一路画面，检测完成后逐格环形刷新最新图片；绿色/红色已不再叠加显示
  在画面上，判定结果看标题栏计数与存图目录（OK/NG 子目录）。
- **底部状态栏**：显示流程当前阶段（等扫码到位 / 等相机到位 / 拍照中 / 配方切换完成等）。

## 三、日常操作

### 3.1 切换产品配方
- 直接点标题栏的**配方下拉框**，选目标配方即切换。
- 切换成功后状态栏变绿显示"配方切换完成"；若 PLC 主站未连入，显示黄色
  "配方已缓存，PLC 主站未连入"，主站连入后自动拉取（无需重操作）。

### 3.2 产品序列号（SN）
- 正常流程：扫码枪扫到条码自动填入（TCP 模式连上后自动发触发指令 `LON` 进入读码状态；
  串口模式上电即读码），标题栏"序列号:"实时更新。
- **手动输入（V1.12.19）**：无扫码枪、或扫码枪没读到码时，**鼠标点击标题栏"序列号"框**
  直接出现输入光标即可录入（无需弹窗）。交互：
  - **回车（Enter）**：提交生效（可随时补录，流程中也能改）；
  - **失焦**（点其它区域）：输入非空同样提交，空输入还原为上值（防误清空）；
  - **Esc**：放弃本次输入，还原为当前 SN。
  与扫码枪收码等效：存图目录同步按新 SN 归档，且在"等 SN"阶段输入会立即推进到拍照阶段。
- 序列号决定存图目录 `{年月日}/{SN}/OK|NG/`，换产品请确保 SN 正确。

### 3.3 放大查看某路画面（V1.12.15）
- **双击**任一显示窗口 → 该窗口全屏放大（覆盖整屏含任务栏），画面仍随检测实时刷新。
- **再次双击 / 按 Esc** → 还原回窗口矩阵原位置。
- 想换成另一路：全屏状态下直接双击另一窗口即切换。

### 3.4 查看来料图片
- 图片按模板自动归档到 `Config/appconfig.json` 的 `image.rootDir` 目录，默认结构：
  `根目录 / 年月日 / SN号 / OK|NG / 点位号.png`。
- 同 SN / 同判定 / 同点位二次拍照自动追加 `_2/_3…` 序号，不覆盖历史图。

## 四、登录账号（V1.9.0 / V1.12.0）

| 账号 | 默认密码 | 登录后进入 | 权限 |
| --- | --- | --- | --- |
| `admin` | `admin123` | 系统设置窗体 | 改配置、保存即热生效 |
| `dev` | `dev123` | 功能测试窗体 | 只做通讯手动验证，**不改配置** |

- 点"系统设置"按钮弹出登录框；密码错误会提示，**连续输错有次数限制**。
- 登录框内置**修改密码**面板（仅管理员可改）：验证原密码 → 新密码两次一致且 ≥6 位 → 保存。
- **记住密码**：勾选后用户名+密码用 Windows 账户加密保存在本机
  （`%LOCALAPPDATA%\CommandCenter\`，管理员 `remembered_login.dat`、开发者 `remembered_login_dev.dat`），
  下次自动回填；换 Windows 用户/换机失效。**V1.12.21：管理员与开发者记录互斥**——登录任一
  账号成功会清除另一账号的记住记录（如上次记住了 dev，这次用 admin 登录后 dev 不再自动回填），
  防止免密入口跨角色残留。
- 管理员密码只存 SHA-256 哈希，改哈希需通过登录框"修改密码"入口，不要手改配置。

## 五、系统设置（管理员）

登录 `admin` 后进入。所有修改点保存即热生效（免重启，设备短暂断连后自动连回）。

- **PLC**：监听绑定 IP（默认 `0.0.0.0`=所有网卡）、端口（默认 502）、从站 UnitId、
  到位 / 开始 / 完成 / 配方 / 配方标志 / 计数等寄存器 D 地址（现场定稿后只改这里）。
- **相机**：表格最左是只读**序号**列（=相机 ID，相机1=1、相机2=2…，删除某台后自动重排）；
  其余每台相机 IP、指令端口、取图方式（V1.12.18 起仅 FTP 推图，Tcp 已下线）、触发指令、超时等。
  相机台数=表格行数，增删即生效。⚠️ 若某台相机触发直接失败且日志报"设置判定输出格式失败"，
  多半是该相机"判定输出格式"列填了非法值（必须恰好 2 位数字，如 `00`）。
**点位→相机程序号（V1.12.25 按相机分表，V1.12.26 起下拉选择）**：现场"28 个窗口点位由两台相机
   分工拍摄"（上相机管一部分点位、下相机管另一部分），每台相机的程序库互相独立——点位→程序号
   按**相机各自配置一张表**，表里配了哪些点位就是这台相机负责拍哪些点位。入口在"窗口/点位配置…"，
   和最上面的窗口↔存图点位矩阵**同一个对话框**：下半区"相机程序映射"选相机后，
   **点位/相机程序号两列都用下拉选择**——**点位列=窗口点位（数量=窗口数）**，程序号列=
   "不切换"+0~127（**程序按相机实际装的程序动态选，数量和编号与窗口数无关**；程序 0 也算一个程序、
   选中"不切换"=保持相机当前程序；某点位不归这台相机拍直接删掉该行）。
   一台相机一行表 = 一台相机的独立映射；设置页相机表加一行新相机，新相机自然有自己的空表，也能
   立刻下拉配置，配好点确定写回、点保存生效（保存不会丢映射）。
  主界面相机下拉/状态灯**有名称（`name` 字段，如上相机/下相机）显示名称，无名称显示"相机N"**，
  N 即设置表里的序号。
- **扫码枪**：TCP 表（IP/端口/触发指令 LON）+ 串口表（串口名/波特率/停止位/校验位），
  启用勾选后才接入。
- **显示**：窗口行数×列数、标题栏字段开关、OK/NG 颜色名、窗口→存图点位映射 + 点位→相机程序号
  （都在"窗口/点位配置…"对话框：上区改窗口对应的存图点位 / 交换位置 / 恢复默认，
  下区"相机程序映射"选相机下拉配点位→程序号，V1.12.25 同页混排、V1.12.26 下拉选择）。
- **图像**：保存根目录、"配置目录结构…"（逐级目录 + 文件名规则 + 实时预览）、FTP 监听目录。
- **安全**：管理员登录开关、账号、记住密码相关（账号维护在登录框完成，见 §四）。

> ⚠️ **FTP 取图（V1.12.22 定稿）**：FTP 推图由**基恩士工程师在相机软件（IV Navigator）里
> 配置**，相机作 FTP 客户端把照片推到**本机 `D:\IV存图\1`（相机1/上相机）与 `D:\IV存图\2`
> （相机2/下相机）**两个目录；上位机不装任何 FTP 服务器软件（FileZilla 等一概不用），程序按
> 相机配置 `ftpUploadDir` 监听这两个目录取图（`image.ftpRootDir` 仅作留空兜底）。
> 若现场 Ftp 模式图不到，先核对相机侧推图目标目录与 `cameras[i].ftpUploadDir` 是否一致。
> **双文件约定（V1.12.18；V1.12.24 起取图扫目录取最新文件）**：每次拍照相机生成 jpeg+iv4p 两个文件
> （**文件名不保证是 0000，可能是 0084 等任意编号**），程序按扩展名配对、两个都到齐才算图到位，
> 归档时**自动扫该相机 FTP 目录取修改时间最新的一对**（事件漏报也能兜底取到），**归档到正式存图
> 目录后会自动删除 FTP 源文件**（FTP 目录只当中转暂存区，处理即删，同一目录里新旧图不会混淆）。

## 六、功能测试（开发者）

登录 `dev` 后进入 `DevTestForm`，用于 PLC 业务逻辑未写完时单独验证通讯链路：

- **相机**：T1 仅触发 / **T2 触发+读判定+取图存图**（V1.12.24：点 T2 拍照后自动从该相机 FTP 取图
  目录拿**最新** jpeg 闪图，并按主窗体设置的存图目录归档一份，**点位固定 1**，路径显示在右侧与日志里；
  **归档成功后自动删除该相机 FTP 取图目录里的源图**（V1.12.25，与主流程"处理即删"一致，测试多次
  拍照不会把相机目录越堆越多）；
  若提示"取图失败"，先看该相机 FTP 目录里有没有新图、推图目标目录是否配置一致）。
  - **切程序（V1.12.20，基恩士侧调试中）**：`读当前程序号`（PR）→ 显示当前 `Pxxx`；
    `切换程序→P001` / `切换程序→P002`（PW,001 / PW,002）→ 切换成功会自动读回确认。
    现场有多个点位程序（P000/P001/P002…）时，先切程序再点 T2 验证连拍。
- **PLC**：读地址 / 写地址测试（含协议偏移量配置），到位 / 触发 / 完成 / 配方信号手动模拟。
- **扫码枪**：实时展示收到的条码，可手动重发触发指令 `LON`。

⚠️ 复用主窗体已建连接、不新建连接；**业务流程运行时不要在测试页操作 PLC 握手寄存器区**
（D100~D112），会干扰生产流程。

## 七、常见问题排查（现场速查）

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| PLC 灯红 | 502 端口被占用 / 绑定 IP 不对 / 防火墙未放行 | 悬停灯看提示；查端口、防火墙入站 502 |
| PLC 灯黄 | 从站就绪但主站未连入 | 检查 PLC 主站程序是否运行、是否指向本机 IP:502 |
| 扫码枪一直断连 | 调试助手等工具占着连接（扫码枪单客户端） | 关闭调试助手连接再重启本程序 |
| Ftp 模式图不到 | 相机侧 FTP 推图未配置好 / 推图目标目录与程序监听目录（相机 `ftpUploadDir`，默认 `D:\IV存图\1/2`）不一致 / 相机还没推图（取的是目录里最新的一张，命名是 0000 或 0084 等任意编号都行） | 联系基恩士工程师核对相机推图目标目录（应分别指向本机 `D:\IV存图\1` 与 `D:\IV存图\2`）；上位机无需部署任何 FTP 服务器；确认目录里确实有刚拍的 jpeg |
| 界面点按钮半天没反应 | 把网络操作放 UI 线程（正常不应发生） | 重启程序；日志报给维护方 |
| 放大窗口没反应 | 双击落在非图片区域 | 双击应落在图像区（整个窗口）即可 |

## 八、换场地 / 换设备怎么改

所有通讯参数都在 `Config/appconfig.json`（或设置窗体可视化修改），**现场改配置即可，不改程序**：

- 换相机/扫码枪 IP：改 `cameras[].ipAddress` / `scanners[].ipAddress`。
- 相机程序号（V1.12.25 起按相机分表，V1.12.26 起下拉选择）：在"窗口/点位配置…"对话框下半区
  "相机程序映射"里，选相机后从下拉选该相机的"点位→程序号"（**点位=窗口点位，数量=窗口数**；
  程序号="不切换"或 0~127，**按相机实际装的程序动态选，数量/编号与窗口数无关**；某点位不归这台
  相机拍直接删行）；或直接改 `cameras[].stationPrograms`（`[{"stationNo":1,"programNo":0},…]`）。
  触发前程序按本轮点位查本相机表自动发 `PW,nnn` 切换，没配的点位不切。**新增相机（设置表加一行）
  自动有自己的空表**，配好后点保存映射不会丢。
- 换 PLC 地址：改 `plc.ipAddress`（上位机固定 IP 需先配到网卡再填同值）。
- 换扫码枪触发指令：改 `scanners[].triggerCommand`（如非 `LON`）。
- 调整窗口矩阵：改 `display.rows/columns`。
