# 基恩士相机通讯联调清单（快速调通专用）

> 用途：现场快速调通上位机（本程序）与基恩士 IV4 系列相机的通讯。
> 本清单把"需要向相机/现场工程师确认的信息"一次性列全，按 **必须确认** 和 **建议确认** 分级，
> 可直接整段转发给对方工程师，对方逐项回填即可。
>
> 对应代码：`CommandCenter/Services/KeyenceIV4Camera.cs`（指令/解析）、
> `CommandCenter/Models/AppConfig.cs` 的 `CameraConfig`（全部可配项）。
> 协议细节以《IV4 系列通信、连接指南》为准。

---

## A. 必须确认（通讯能通的前提）

1. **相机型号 + 固件版本**
   - 确认支持 "TCP/IP 无协议通信"，并确认几路（IV4 最多 2 路；程序每台相机只占 1 路）。
2. **相机 IP / 子网掩码 / 上位机 IP**
   - 是否同一网段、能否互 ping 通。
3. **无协议通信命令端口号**
   - IV4 Navigator → 以太网 → TCP/IP 无协议通信 里设置的**端口号**（不一定是 8500）。
   - 程序默认 `8500`（`CameraConfig.CommandPort`），按实际改。
4. **指令/响应格式逐字确认**（关键！用网络调试工具连相机实测，回显截屏/文字发回）
   - 发 `T1`（+回车）→ 相机回什么？（应为回显 `T1`，确认结尾是 CR 还是 CRLF）
   - 发 `T2`（+回车）→ 相机回什么？（应为判定帧，确认判定字段长什么样）
   - 发 `RT`（+回车）→ 相机回什么？（同上，单独读判定）
5. **触发源**：本次联调用**上位机软件触发**（程序发 T2），还是 **PLC 给相机硬触发**？
   - 程序只负责"软件触发"这一路；若现场用硬触发，需确认触发后判定能否用 `RT` 读到。

## B. 判定（决定 OK/NG 准不准）

6. **判定工具配置了几个工具**：`RT,` 后面到底几位字符（程序按循环逐位解析，几位都兼容，但要确认含义）。
7. **每位字符含义**：`0`=合格？`1`=不合格？`4`=未进行？`-`=未启用？
   - 拿 **1 块 OK 样件 + 1 块 NG 样件** 各触发一次，把 `RT,` 后的完整字符串发回。
8. 现场**是否已配置判定工具**？没配的话只能走退化模式
   （`ReadResultFromCamera=false`：FTP 图到即记 OK），确认是否接受。

## C. 取图（两条路，二选一）

9. **取图方式选哪个？**
   - **Ftp 取图（默认，成熟）**：相机作 FTP 客户端推图到上位机。
     需确认相机 Navigator 里 FTP 客户端参数（FTP 服务器地址=上位机、账号/密码、
     上传目录、文件命名规则）；**上位机必须装 FTP 服务器**（FileZilla Server 等）落盘。
   - **Tcp 直读取图（免 FTP，推荐快速联调）**：程序发 `BR,1` 直接读回最新图。
     需确认调试工具实测 `BR,1` 返回：
     - 响应头两个数字：第一个=**合计触发编号**，第二个=**图像数据字节长度**；
     - 二进制**是不是直接就是 BMP（`BM` 开头）**？若返回裸像素（无文件头），
       把格式（宽/高/24bit）发回，程序需补文件头。

## D. 联调时改哪些配置

> 确认完以上项后，把关键值填进 `程序目录\Config\appconfig.json` 的 `cameras` 数组节点
> （也可在系统设置窗体"相机"表格里可视化修改，改完保存即生效，无需重启）。

| 配置字段 | 含义 | 联调时常见值 |
| --- | --- | --- |
| `ipAddress` | 相机 IP | 按现场 |
| `commandPort` | 无协议通信端口 | 8500 或按 A3 |
| `imageSource` | 取图方式 | `"Ftp"` 或 `"Tcp"` |
| `triggerAndReadCommand` | 触发+读判定指令 | `"T2"` |
| `triggerCommand` | 仅触发指令 | `"T1"` |
| `readResultCommand` | 单独读判定指令 | `"RT"` |
| `okChar` | 判定合格字符 | `"0"` |
| `readResultFromCamera` | 判定是否来自相机 | `true`（未配判定则 `false`） |
| `responseTimeoutMs` | 等判定/取图响应超时 | 5000，现场相机慢可调大 |
| `readImageMode` | BR 压缩率 | `"0"`=无压缩，`"1"`=1/2（默认） |

---

## 快速联调建议路径

1. 先完成 A1~A4（型号/IP/端口/指令实测帧）——这是卡脖子的；
2. 用调试工具连相机发 `T1` / `T2` / `BR,1`，把回显发给上位机开发侧；
3. 选一条取图路（C9 建议先 `Tcp`，免装 FTP 服务器）；
4. 按 D 表填配置 → 启动程序 → 触发一次看标题栏 OK/NG 与窗口图片。
