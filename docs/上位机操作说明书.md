> **写给谁看**：现场操作员、班组长。
> **这本讲什么**：开机、看界面、日常操作、遇到问题怎么办。不讲内部原理。

## 一、开机与启动

1. 打开电脑，等 Windows 启动完。
2. 双击桌面上的 **CommandCenter**（上位机检测程序）图标。
3. 等 2~3 秒，**主界面自动铺满屏幕**，出现一排排的检测窗口就说明启动成功。
4. 正常生产**不需要登录**。只有维护人员改参数时，点右上角"系统设置"才需要输入管理员账号。

> 启动失败怎么办：看看电脑右下角有没有报错；确认 `Config` 文件夹没被动过。还是起不来就叫工程师，**不要自己删文件**。

逐个说明：

| 位置 | 名称 | 是什么 / 怎么看 |
| --- | --- | --- |
| 左上 | **产品型号** | 当前正在做的产品型号。点下拉可以直接切换，切换后相机自动换对应程序，**设备不用重启** |
| 中间 | **序列号** | 当前这一件产品的条码。扫码枪扫到会自动填进来（只读显示） |
| 按钮 | **【人工补录】** | 扫码枪没扫到码时，手动输入/修改条码用 |
| 标题栏 | **总数 / OK / NG** | **当前这一个工件**的检测点数：OK=绿色、NG=红色。每来一件新产品会自动清零重数 |
| 右上角 | **● 圆点灯** | 四个灯：PLC、扫码枪、相机1、相机2。**绿=正常，红=有问题**（PLC 黄色=在等主站，属正常） |
| 右上角 | **语言切换** | 标题栏最右侧的 **English/中文** 按钮（中文界面显示 English、英文界面显示 中文）。点击立即在中/英文界面之间切换，并自动保存，重启仍保持 |
| 中间 | **窗口矩阵** | 每一格是一个检测点位的相机画面。拍完自动刷新最新图片；格子右下角**绿色框=这个点OK、红色框=NG** |
| 底部 | **状态栏** | 现在系统在干什么：等扫码、拍照中、切型号等 |

> **提醒**：每次新工件到位，所有窗口会先清空变深灰色、计数归零，这是正常现象，说明这一件从头开始检测了。

## 三、每天的标准流程

1. 开机启动程序。
2. 确认右上角四个圆点灯：**PLC、扫码枪、相机1、相机2 都要绿**（黄色 PLC 可以等）。有红的先别开工，看第八节。
3. 确认左上角**产品型号**是今天要做的型号，不对就点下拉切换，等状态栏显示"型号切换完成"。
4. 放工件 → 扫码枪自动读条码 → 相机自动拍照 → 窗口逐格出图 → 每个点自动判定 OK/NG。
5. 正常生产时**不用操作**，看着窗口画面和计数即可。

---

## 四、序列号（SN）——很重要

- **正常**：扫码枪扫到条码，会自动显示在"序列号:"后面，不用管。
- **扫码枪没扫到、或扫错了**：点旁边的**【人工补录】**按钮 → 弹出输入框 → 输入或修改条码 → **按回车确定**（按 Esc 取消）。
- 输入时注意：**不能填空**确定；真不要这个码就点取消。

> ⚠️ 序列号决定照片归档到哪个文件夹（`日期/条码号/...`），**条码不对，照片就存错地方**。每次换工件留意一下序列号是否跟工件一致。

## 五、扫码枪出问题（重点看这条）

### 现象
屏幕上弹出提醒：**"扫码枪异常，请检查扫码枪或进行人工补录"**。

### 原因
扫码枪这一下没读到码（条码脏/距离远/枪的线松了/枪坏了）。

### 怎么办（按顺序）
1. **看一眼枪**：激光有没有在闪、线有没有松。把条码放正、放近一点再试。
2. **枪恢复后**：弹窗会自动关闭，什么都不用做。
3. **一时修不好**：点**【人工补录】**，手动输入这一件的条码，生产继续往下走。
4. **点【稍后处理】**：只表示"先不烦我"，**这一件还欠着条码**，程序会一直等——稍后一定要通过【人工补录】补上，否则流程卡住。
5. 弹窗里有 **☐ 今日不再提醒**：勾上后今天之内不再弹窗（件照样要补录，只是不吵你了）。适合"枪已经报修、今天就用补录顶着"的情况。

> ⚠️ **弹窗不是没事发生，是这一件的码没读到**。不要一直点【稍后处理】当没看见——**不补录，这一件就过不去**。

## 六、放大看某一格的画面

- **双击**任意一个窗口 → 全屏放大看细节（放大后画面照常实时刷新）。
- **再双击一次 / 按 Esc** → 还原回原位。
- 全屏时想看别的格子：直接双击另一个窗口即可切换。

## 七、照片存在哪里（查图找档）

- 程序自动把每次检测的照片存到电脑的图片目录，结构是：

```
E:\Images（图片根目录）
 └─ 2026.08.20（日期，点分隔）
     └─ SN12345（条码号）
         └─ 上相机（哪个相机拍的）
             ├─ OK（这个点判定合格）
             └─ NG（这个点判定不合格）
                 └─ 001_20260817_164022_461.jpeg（照片）
```

- 想查某一件的照片：让组长/工程师打开对应文件夹即可。
- **照片默认保留 30 天自动清理**，重要的早点拷走。

## 八、连接灯红了怎么办（现场速查）

> **颜色速认（V2.15.11 起）**：连接灯只有两种状态——**绿=正常、红=有问题**（PLC 多一个
> **黄=在等主站**）。**没有灰色**：开机就直接显示真实状态；如果一台启用枪都没配，右上角
> **扫码枪那盏灯会消失**（表示没有枪，不是坏了）。

| 现象 | 什么意思 | 操作员怎么办 |
| --- | --- | --- |
| **PLC 灯红** | PLC 通讯断了 | 别开工，叫工程师 |
| **PLC 灯黄** | 在等 PLC 主站连进来 | 正常等待，不用管 |
| **扫码枪灯红** | 扫码枪没连上 | 检查枪的线/电源；按第五节用【人工补录】顶着 |
| **相机灯红** | 相机通讯断了 | 叫工程师（查相机网线/推图配置） |
| **窗口一直不出图** | 相机拍了但图没到 | 叫工程师看，别反复触发 |
| **个别格子从不拍照** | 这一格是"空窗口"（没分配检测点位） | 属正常现象，不用管 |

## 九、操作禁忌（红线，务必遵守）

1. **不要点"系统设置"**——需要管理员密码，是维护人员改参数的，操作员不要进。
2. **不要动电脑上其他窗口、不要关防火墙、不要拔网线**。
3. **不要手动删/改图片文件夹里的文件**。
4. 出现弹窗或异常，**先按提示处理，处理不了就叫工程师**；不要直接重启电脑（会丢当前工件数据）。
5. **不要私自改动产品型号**，换型号要按组长安排来。

## 常见问题一句话速答

- **问**：窗口怎么都是深灰色？
  **答**：新工件开始，窗口刚清空，等相机拍完会自动出图。一直不出图就按第八节处理。

- **问**：计数一直不动？
  **答**：看状态栏是不是停在某一步；有弹窗就先处理弹窗；不行叫工程师。

- **问**：型号选错了怎么办？
  **答**：点左上角型号下拉，选回正确的型号，等状态栏"型号切换完成"即可，不用重启。

- **问**：弹窗点掉后生产怎么还不动？
  **答**：多半是这一件的条码还没补（见第五节第4条），点【人工补录】补上码就好了。
