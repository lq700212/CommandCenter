# Modbus TCP 通信接口定义文档

**文档版本：** V2.14.14
**适用项目：** 机器人视觉取像系统（含扫码）
**通信模式：** 汇川PLC（主站/Master） ↔ C#上位机（从站/Slave）

## 一、通信连接参数

| 参数项              | 取值          | 备注                            |
| :------------------ | :------------ | :------------------------------ |
| 通信协议            | Modbus TCP    | 基于以太网                      |
| 上位机（从站）IP    | `19.87.6.230` | 固定，请勿变动                  |
| PLC（主站）IP       | `19.87.6.1`   | 由PLC工程师分配确认             |
| 端口号              | `502`         | Modbus TCP默认端口              |
| 从站地址（Unit ID） | `1`           | 待双方确认                      |
| 地址偏移            | **无**        | 实测确认，PLC地址与协议地址一致 |

## 二、寄存器地址映射表

> **寄存器类型说明**：保持寄存器（Holding Register）为16位（Word），可读可写。
> **地址编号说明**：PLC地址与协议地址一致（实测确认无偏移）。
> **设计原则**：定长数据（请求）放在最前面，结果与变长数据（型号序号+型号字符串）放在后面，分类清晰，便于PLC侧顺序配置。
> **V2.14.13 协议升级**：产品型号区拆成"型号序号 + 型号字符串"两部分——`40007` 存**型号对应的序号**
> （现场默认 Z121=1、U171=2，上位机配置 `plc.modelIndexes`），`40008~40012` 存型号 ASCII 字符串
> （原 `40007~40011` 整体后移一位）。PLC 读取型号时**优先用 40007 的序号**区分型号，无需解析字符串。

| :--- | :-------- | :------------------- | :-------------- | :------------ | :-------------------------------------- |
| 1    | **40001** | 扫码请求             | **PLC只写**     | `0` 或 `1`    | `0`=无请求，`1`=请求扫码                |

| 9    | **40009** | 产品型号（字符3-4）  | **PLC只读**     | ASCII字符     | 高字节=字符3，低字节=字符4              |
| 10   | **40010** | 产品型号（字符5-6）  | **PLC只读**     | ASCII字符     | 高字节=字符5，低字节=字符6              |
| 11   | **40011** | 产品型号（字符7-8）  | **PLC只读**     | ASCII字符     | 高字节=字符7，低字节=字符8              |
| 12   | **40012** | 产品型号（字符9-10） | **PLC只读**     | ASCII字符     | 高字节=字符9，低字节=字符10             |

### 2.2 地址分类速查

#### PLC → 上位机（PLC只写，上位机读取）

| PLC地址 | 寄存器名称     | 取值说明                     |
| :------ | :------------- | :--------------------------- |
| 40001   | 扫码请求       | `0`=无请求，`1`=请求扫码     |
| 40002   | 请求拍照上相机 | `0`=无请求，`1~255`=点位编号 |
| 40003   | 请求拍照下相机 | `0`=无请求，`1~255`=点位编号 |

#### 上位机 → PLC（PLC只读，上位机写入）

| PLC地址     | 寄存器名称         | 取值说明                                  |
| :---------- | :----------------- | :---------------------------------------- |
| 40004       | 扫码结果           | `0`=默认，`1`=OK，`2`=NG                  |
| 40005       | 上相机拍照结果     | `0`=默认，`1`=OK，`2`=NG                  |
| 40006       | 下相机拍照结果     | `0`=默认，`1`=OK，`2`=NG                  |
| 40007       | 产品型号序号（V2.14.13） | `0`=未配置，`1~255`=型号对应序号（默认 Z121=1、U171=2） |
| 40008~40012 | 产品型号（10字符） | ASCII编码，每寄存器存2字符，不足补 `0x00` |

### 2.3 地址布局示意图

```text
地址范围         内容                              方向（PLC视角）
─────────────────────────────────────────────────────────────────
40001 ~ 40003    请求区（扫码/上相机/下相机）       PLC只写
40004 ~ 40006    结果区（扫码/上相机/下相机）       PLC只读
40007            型号序号区（V2.14.13，型号对应序号）PLC只读
40008 ~ 40012    型号区（10字符，5个寄存器）        PLC只读
40013 ~ ...      预留                              可向后扩展
```

> **扩展说明**：若后续型号长度超过10个字符，可直接从 `40013` 开始向后增加寄存器，不影响 `40001` ~ `40012` 的请求/结果/序号地址，双方无需修改已有逻辑。

### 2.4 产品型号（序号 + 字符串）编码说明

- **型号序号（V2.14.13，`40007`）**：每个产品型号对应一个序号，现场默认 `Z121=1`、`U171=2`（上位机
  设置窗体 PLC 区"产品型号配置…"按钮弹窗 **ModelIndexEditForm** 表格维护，V2.14.14 起取代旧
  "型号序号"单行框，存 `plc.modelIndexes` 映射，见 §2.4 型号来源）。PLC **优先用 40007 的序号**
  区分型号，速度快、不受型号名长度影响；`0`=该型号未配序号。
- **型号字符串（`40008` ~ `40012`）**：共5个寄存器，最多可传递 **10个ASCII字符**。
- 每个寄存器存放两个字符：**高字节（Bit 8~15）= 前一字符，低字节（Bit 0~7）= 后一字符**。
- **示例**：型号为 `"Z121"`（序号=1），则：
  - `40007 = 0x0001`（型号序号=1）
  - `40008 = 0x5A31`（'Z'=0x5A，'1'=0x31）
  - `40009 = 0x3231`（'2'=0x32，'1'=0x31）
  - `40010 = 0x0000`（字符串结束）
  - `40011 ~ 40012 = 0x0000`
- 不足10个字符的，在最后一个有效字符后面填 `0x00` 表示字符串结束。
- 若后续发现型号超过10个字符，从 `40013` 开始向后扩展即可。
- **型号来源（V2.8；V2.14.24 入口唯一化）**：**当前型号** = 上位机主界面标题栏型号下拉选择
  （候选=预置 `U171`/`Z121` ∪ 配置 `productModels`）；**型号集合**（增删新型号）统一在设置窗体
   PLC 区"产品型号配置…"弹窗（ModelIndexEditForm）维护——新增型号名保存时自动回流进
  `productModels`（ConfigStore.EnsureModelIndexes 双向对齐），主界面标题栏即可选到；
  **型号序号（V2.14.14）**在 PLC 区"产品型号配置…"按钮
  弹窗（ModelIndexEditForm）里表格维护（V2.14.25 三列=选中勾选列/序号/型号名称，全居中，
   右上角"删除选中"按钮勾选多行批量删 / 点选单选多选删；前几行预载已有映射，确定写回
  `plc.modelIndexes`、取消不影响原配置；取代 V2.14.13 的"型号序号"单行框）。
- **型号写入时机（V2.14.14）**：型号区（40007=序号 + 40008~40012=字符串）不再只等扫码通道推进才写，
  而是三时机写：① **每次扫码推进时写**（原行为）；② **从站建站成功即写**（`PlcService.SetCurrentModel`
  缓存型号，`EnsureConnected` 建站成功即写，覆盖上电/断线重建/热更重建，PLC 不触发扫码也读得到）；
  ③ **主界面切型号立即下发**（`SwitchModel` 更新并重写）。PLC 随时能读到当前型号。
  **型号同时决定相机程序映射**（`modelStationPrograms`，见 `docs/CommandCenter.md` §4）：切型号即切换
  对应的"点位→相机程序号"表，触发相机时按新型号发 `PW,nnn` 切程序。

## 三、功能码约定

| 操作                      | 功能码（十进制） | 说明                                                         |
| :------------------------ | :--------------- | :----------------------------------------------------------- |
| PLC读取 `40004` ~ `40012` | 03（0x03）       | 读保持寄存器                                                 |
| PLC写入 `40001` ~ `40003` | 16（0x10）       | 写多个保持寄存器（批量） （也支持单个写入功能码06，批量更高效） |

> **说明**：PLC侧使用功能码16（写多个寄存器）批量写入请求数据，符合标准Modbus规范，上位机NModbus库可自动解析，无需额外适配。

## 五、异常处理约定

| 异常情况                      | 处理方式                                                     |
| :---------------------------- | :----------------------------------------------------------- |
| 扫码超时（如5秒未返回SN）     | 上位机写 `40004 = 2`（NG），界面报警"扫码超时"，流程继续     |
| 上相机拍照超时（如5秒未完成） | 上位机写 `40005 = 2`（NG），界面报警"上相机拍照超时"，流程继续 |
| 下相机拍照超时（如5秒未完成） | 上位机写 `40006 = 2`（NG），界面报警"下相机拍照超时"，流程继续 |
| 通信中断                      | 上位机界面显示"通信中断"，PLC侧建议做超时保护（如3秒未收到反馈则报警） |

## 六、PLC侧配置要求

1. 请将上述 `40001` ~ `40012` 共12个寄存器，按**连续地址**映射到PLC内部可读写的地址区域。
2. 请确保PLC的Modbus TCP主站功能已开启，目标从站IP = `19.87.6.230`，端口 = `502`，Unit ID = `1`。
3. **地址无偏移**：实测确认，PLC写入地址与上位机读取地址一致，无需做 `-40001` 换算。
4. **功能码16写入**：PLC可使用功能码16（0x10）一次性写入 `40001` ~ `40003` 等多个请求值，上位机NModbus库可正常解析。
5. 建议PLC程序中，对请求信号的置位加入防抖延时（建议100ms），避免机器人抖动导致误触发。
6. **寄存器使用说明**：
   - `40001`：PLC写入扫码请求，上位机读取
   - `40002`：PLC写入上相机拍照请求（点位编号），上位机读取
   - `40003`：PLC写入下相机拍照请求（点位编号），上位机读取
   - `40004`：上位机写入扫码结果，PLC读取
   - `40005`：上位机写入上相机拍照结果，PLC读取
   - `40006`：上位机写入下相机拍照结果，PLC读取
   - `40007`：上位机写入**型号序号**（V2.14.13，默认 Z121=1、U171=2，`0`=未配序号），PLC读取
   - `40008` ~ `40012`：上位机写入型号字符串（最多10字符），PLC读取
7. **型号识别建议（V2.14.13）**：PLC 侧优先读 `40007` 的序号判断当前型号（数值比较最快最稳），
   型号字符串 `40008~40012` 作辅助信息（如显示/日志）；未配序号的型号（40007=0）才回退解析字符串。
8. **字符串结束符**：PLC读取型号时，以 `0x00` 作为字符串结束标志，0x00之后的字节忽略。
9. **扩展预留**：若后续型号长度超过10个字符，从 `40013` 开始向后扩展，不影响已有地址。

## 七、上位机代码示例（C#）

### 7.1 读取PLC请求

```csharp
// 读取扫码请求（40001）
ushort[] scanReq = master.ReadHoldingRegisters(40001, 1);
bool isScanRequested = scanReq[0] == 1;

// 读取上相机拍照请求（40002）
ushort[] camUpReq = master.ReadHoldingRegisters(40002, 1);
int camUpPoint = camUpReq[0];  // 0=无请求，>0=点位编号

// 读取下相机拍照请求（40003）
ushort[] camDownReq = master.ReadHoldingRegisters(40003, 1);
int camDownPoint = camDownReq[0];  // 0=无请求，>0=点位编号
```

### 7.2 写入扫码结果（40004）

```csharp
// 扫码OK
master.WriteSingleRegister(40004, 1);
// 扫码NG
master.WriteSingleRegister(40004, 2);
// 复位
master.WriteSingleRegister(40004, 0);
```

### 7.3 写入拍照结果（40005 / 40006）

```csharp
// 上相机OK
master.WriteSingleRegister(40005, 1);
// 上相机NG
master.WriteSingleRegister(40005, 2);
// 下相机OK
master.WriteSingleRegister(40006, 1);
// 下相机NG
master.WriteSingleRegister(40006, 2);
// 复位
master.WriteSingleRegister(40005, 0);
master.WriteSingleRegister(40006, 0);
```

### 7.4 写入产品型号（40007=型号序号 + 40008~40012=型号字符串）

```csharp
/// <summary>
/// 写产品型号（V2.14.13 格式）：先写 40007 型号序号（查 plc.modelIndexes 映射，型号没配写 0），
/// 再写 40008~40012 型号 ASCII 字符串（最多10个字符）。
/// 调用时机（V2.14.14 三时机）：每次扫码推进 / 从站建站成功 / 主界面切型号立即下发。
/// </summary>
public void WriteProductModel(string model, int modelIndex)
{
    // ① 型号序号 → 40007（V2.14.13）
    master.WriteSingleRegister(40007, (ushort)modelIndex);

    // ② 型号字符串 → 40008~40012
    byte[] bytes = new byte[10];
    byte[] modelBytes = Encoding.ASCII.GetBytes(model);
    int len = Math.Min(modelBytes.Length, 10);
    Array.Copy(modelBytes, bytes, len);
    // 末尾自动补0（已初始化全0）

    List<ushort> registers = new List<ushort>();
    for (int i = 0; i < 10; i += 2)
    {
        ushort value = (ushort)((bytes[i] << 8) | bytes[i + 1]);
        registers.Add(value);
    }

    master.WriteMultipleRegisters(40008, registers.ToArray());
}

// 调用示例：型号 "Z121"（序号=1）
WriteProductModel("Z121", 1);
// 写入后：
// 40007 = 0x0001（型号序号=1）
// 40008 = 0x5A31 ('Z','1')
// 40009 = 0x3231 ('2','1')
// 40010 = 0x0000 (字符串结束)
// 40011~40012 = 0x0000
```

### 7.5 PLC侧读取型号（序号 + 字符串，参考）

```csharp
// PLC读取 40007（型号序号）+ 40008~40012（型号字符串）共6个寄存器
ushort[] data = master.ReadHoldingRegisters(40007, 6);
int modelIndex = data[0]; // 40007 = 型号序号（V2.14.13，优先用序号区分型号）

// 40008~40012 转10字节
byte[] bytes = new byte[10];
for (int i = 0; i < 5; i++)
{
    bytes[i * 2] = (byte)(data[i + 1] >> 8);
    bytes[i * 2 + 1] = (byte)(data[i + 1] & 0xFF);
}

// 截取到第一个 '\0' 结束
int end = Array.IndexOf(bytes, (byte)0);
if (end < 0) end = bytes.Length;
string model = Encoding.ASCII.GetString(bytes, 0, end);
```
